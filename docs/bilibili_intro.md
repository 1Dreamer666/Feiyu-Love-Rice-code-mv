# 推荐版

```
大肥鱼干饭手书《肥鱼爱大米》的同人动画 MV。改编自《老鼠爱大米》，部分字眼用 MiMo-V2.5-TTS 的「唱歌」模式替换重唱。主角是 DeepSeek 鲸鱼娘「大肥鱼（深深）」。

【画面】
正片画面全部由纯代码绘制（p5.js / Canvas 2D），没有一张逐帧手绘素材——每一帧都是给定时间 t 后由函数实时算出来的，所以能逐像素复现，也能离线导出成视频。配有卡拉OK式歌词字幕。
封面另用 GPT-image2.5 重绘，含排版重构。

【制作流程】
初始页面由哈吉米4 的 argon 任务模式搭起骨架。
后续完善交给 DeepSeek Harness desktop 开工：分镜、角色、场景、动画代码均由它完成，中途按 polaris0（GitHub: beidou070）的角色形象做了微调。
旧版本未制作视频。

【音频】
先用 Demucs 把人声和伴奏分离，只替换人声轨、保留原伴奏，所以插入改编歌词时伴奏不会断。
再用 WSOLA 做时间伸缩对齐节奏、WORLD 声码器做音高映射完成旋律迁移，最后统一到 -14.5 LUFS 母带响度。

【成本与体感】
花费数十元，会话用量上亿 tokens（含缓存读写）。
体感上像是「许愿式」一句话生成 MV，但真正的成本在于不断重试——最难的是让角色在反复修改中不崩坏。

【源码】
实际输入提示词和确定性渲染管线都在这里：
https://github.com/1Dreamer666/Feiyu-Love-Rice-code-mv

仓库维护与视频发布均由 DeepSeek Harness desktop 负责。

【音乐】
原曲：《老鼠爱大米》
原作：杨臣刚（词曲）

【角色】
角色原型：DeepSeek 鲸鱼娘
女仆鲸鱼娘设计：@ZipZipPipe @这个刀子真甜 @polaris0

【声明】
非商业同人作品。角色衍生部分按 CC BY-NC-SA 4.0 署名、非商业、相同方式共享。
```
